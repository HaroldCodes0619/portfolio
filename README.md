# John Harold Salvaña — Personal Developer Portfolio

Modern, responsive developer portfolio showcasing projects, technical skills, education at Torres Capitol College (TCC), and campus milestones.

![Portfolio Preview](./public/preview.png)

## 🚀 Features

- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.
- **Theme Modes**: Seamless Dark / Light theme toggle with automatic persistence.
- **Hero & Profile Showcase**: Dynamic introduction, interactive avatars with direct upload & transparent cutout processing.
- **Featured Projects**: Curated full-stack & mobile engineering projects with live demos and source links.
- **Interactive Skills Section**: Interactive skill proficiency indicators and tech stack overview.
- **Moments & Highlights Gallery**: Clean photography gallery documenting workspace setups and campus life.
- **Contact & Socials**: Functional contact form with real-time feedback and direct social links.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8
- **Styling**: Tailwind CSS + Custom responsive design system
- **Animations**: Framer Motion / Motion
- **Icons**: Boxicons + Lucide React
- **CI/CD**: GitHub Actions (automatic build and GitHub Pages deployment)

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 20 or higher recommended)
- `npm` or `yarn` or `bun`

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/HaroldCodes0619/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Available Scripts

- `npm run dev`: Starts the local development server on port 3000.
- `npm run build`: Compiles TypeScript and creates optimized production assets in `dist/`.
- `npm run lint`: Runs TypeScript type checking (`tsc --noEmit`).
- `npm run preview`: Previews the production build locally.

## 🌐 Automatic GitHub Pages Deployment

This repository includes a ready-to-use GitHub Actions workflow (`.github/workflows/deploy.yml`).
Whenever code is pushed to the `main` branch, it automatically builds and publishes the website to GitHub Pages:

1. On GitHub, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. Any push to `main` will trigger the workflow and deploy the live site automatically.
